# 精选清单

本目录中的论文从外部目录“载荷轨迹规划/参考文献”中筛选而来，筛选标准是是否直接服务于以下研发链条：

1. 由载荷轨迹反求载荷动力学所需 wrench。
2. 由载荷 wrench 进行多绳索张力分配。
3. 由张力、绳索方向和几何约束反推无人机位置。
4. 为后续仿真验证提供可靠建模参考。

## 当前保留的高价值参考

- `K.S2013(326)RSS(经典建模参考).pdf`
  作用：多无人机绳索悬挂刚体载荷建模的经典入口，优先级最高。

- `T.L2017(214)IEEE_TCST(几何控制).pdf`
  作用：几何控制主线参考，可帮助明确载荷、绳索和飞行器之间的状态耦合关系。

- `K.W2024(15)IEEE_RAL(待细看，很全).pdf`
  作用：直接对应 cable force allocation，是“载荷 wrench -> 绳索张力”这一层的关键文献。

- `J.G2022(17)JAIS（四区，有载荷轨迹规划，无避障）.pdf`
  作用：与载荷轨迹和 load distribution 相关，适合连接规划结果与张力/控制分配问题。

- `J.K CEP提出了耦合性这个问题.pdf`
  作用：针对系统耦合问题，适合作为从 payload-level 模型走向 system-level 反推时的理论补充。

- `Y.W2026(5)TranOnRobot.pdf`
  作用：偏系统级协同运输，可用于参考更高层的多机协同可行性和运输执行方式。

- `H.Y Automatica可变长.pdf`
  作用：涉及 cable length online optimization，对后续“已知/未知绳长”建模选择有价值。

- `L.K2024(30)Automatica-2.pdf`
  作用：涉及 unknown load mass，有助于后续考虑参数不确定性和估计问题。

- `E.L2023(10)AST.pdf`
  作用：提供稳定性与闭式分析角度，适合作为逆推模型的分析性补充。

- `A.T2017(150)IEEE_ICRA（卡尔曼，估计载荷）.pdf`
  作用：偏估计方向，适合在后续需要在线状态/参数估计时接入。

- `H.M2023(28)Alexandria Engineering Journal（综述）.pdf`
  作用：综述性参考，适合补全控制与吊载系统研究背景。

- `G.L2023(36)IEEE_Tran_on_R(仿真工具，参考建模).pdf`
  作用：仿真与建模基线，对后续前向验证平台选择最有帮助。

## 建议阅读顺序

1. 先读 `K.S2013...`、`T.L2017...`、`K.W2024...`。
2. 再读 `J.G2022...`、`J.K...`、`Y.W2026...`。
3. 然后补 `H.Y...`、`L.K2024...`、`A.T2017...`。
4. 最后把 `H.M2023...` 和 `G.L2023...` 当作背景补强与验证平台参考。
